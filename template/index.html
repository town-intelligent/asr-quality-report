混音參數

參數值說明
背景人聲音量0.08ASR 測試通過的最大值；超過 0.15 會導致 Kaohsiung 被誤辨識為關山
白噪音 (white)a=0.03模擬冷氣、電子設備底噪
粉紅噪音 (pink)a=0.02模擬遠處人群嘈雜
回音 (echo)aecho=0.8:0.4:40|80:0.15|0.1模擬車站大廳空間
低通濾波lowpass=5000Hz去除不自然的高頻
高通濾波highpass=150Hz去除低頻隆隆聲

混音指令

# 方法 A：使用預先混合好的背景音軌
ffmpeg -y -i <TTS_INPUT>.mp3 -i golden_background.wav \
  -filter_complex "[0:a][1:a]amix=inputs=2:duration=first:dropout_transition=0" \
  output.mp3

# 方法 B：從素材重新混合（可調整參數）
ffmpeg -y \
  -i <TTS_INPUT>.mp3 \
  -i bg_zh_0.mp3 -i bg_zh_1.mp3 -i bg_zh_2.mp3 -i bg_zh_3.mp3 -i bg_zh_4.mp3 \
  -filter_complex "
    [1:a]volume=0.08,adelay=100|100[bg0];
    [2:a]volume=0.08,adelay=700|700[bg1];
    [3:a]volume=0.08,adelay=300|300[bg2];
    [4:a]volume=0.08,adelay=1100|1100[bg3];
    [5:a]volume=0.08,adelay=500|500[bg4];
    anoisesrc=d=8:c=white:a=0.03[noise];
    anoisesrc=d=8:c=pink:a=0.02[crowd];
    [0:a][bg0][bg1][bg2][bg3][bg4][noise][crowd]amix=inputs=8:duration=first:dropout_transition=0,
    aecho=0.8:0.4:40|80:0.15|0.1,
    lowpass=f=5000,highpass=f=150
  " \
  output.mp3
