觀察到的 failure modes

  • DeepL 翻譯品質：「班車」→ "bus"（應 train）、「美麗島」→ "Belle Isle"（應 Formosa Boulevard）— 這部分 zh→en→TTS 已偏離原意、不能完全怪 MT
  • TTS 發音不精：美式英文唸中文拼音地名失準（"Xinzuoying" 變 "Zhenzhuoying" / "Zinzuling"）
  • TG 偶發「公車車」重複字 bug（en #02 連犯 2 次）— 14B 沒這問題
  • TG 「高美車站」誤譯 vs 14B 「高雄車站」（en clean 案例）— 14B 對地名 prior 更強
  • 所有 TTS 場景 ko、th、vi 兩邊都退化嚴重—（DeepL 翻譯 + 噪音 + ASR 三重）

對 MT engine 決策的意義

1. 數據面進一步支持 14B：跨噪音 level 14B 全面領先（clean +10、light +5、standard +5）、速度仍快 4x。298 真人 retro +1.68% + 384 TTS+noise +5.21% 兩個獨立樣本同方向。

2. 14B 更 robust：在「翻譯品質差 + 多噪音」壓力下、TG 退化比 14B 更快（clean→standard：TG -23 個百分點、14B -28 個百分點、差不多但 14B 起點高）。

3. 但分數絕對值低（51% vs 46%）不能當 production 預期：production 真人錄音預期 99%+、TTS 壓力測試僅供 robustness 比較。

4. ko-男測資缺仍未解：TTS ko-男聲跑了 32 case (4 noise × 2 gender × ... wait 16 case)、不是真人。ko-男聲真人錄音仍缺。
